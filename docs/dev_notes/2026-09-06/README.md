**可用口令模板**（以后复现对账默认用它，不再用 WSL venv）：

要点：
- `cmd.exe /d /c`：/d 避免 UNC 路径报错；必须 `cd /d E:\...` 先切盘
- `set PYTHONIOENCODING=utf-8`：不加会 GBK 编码崩（emoji 🚀 无法输出到文件）
- Windows python = `E:\python\python.exe`（Python 3.13.4 / pandas 2.3.3 / numpy 2.2.6）
- 输出文件 WSL 可直接读（/mnt/e/...）
- cmd 中文输出在 WSL 显示乱码（GBK vs UTF-8 终端），不影响功能

## 六、主力操盘四阶段模型（老板定义 v1，2026-09-06 口述，待打磨未固化）

**世界观前提（老板核心认知）**：对控盘强的主力，一切外部信息（美股/政策/行业）只是他**借势发挥的素材**——用来让砸盘/洗盘/拉升"看起来合理"，让股民脑补故事。真实剧本由主力行为(量/价/换手)决定；**个股层面勿用外部消息解释走势**。例外(大股灾/被别的主力砸)属宏观层级，不在此模型内。

**四阶段**：
1. **砸盘恐吓**：低换手+急跌，制造恐慌吓跑套牢盘；不介意谁接盘，会多次砸、边砸边把自己成本做低。
   ⚠️ 恐吓 vs 真跌分水岭 = **换手率**：高换手+高成交+下跌=真跌(危险)；低换手跌/阴跌=洗盘(不可怕)
2. **吸筹**（前提：恐吓后未发生真跌）：涨涨跌跌但总体向上，"不卖隔一天总有浮盈"（有支撑位托着）；主力不能买太快(买快价格拉升成本高)，慢慢吸、筹码越吸越便宜。
3. **拉升**（吸够筹码后）：两种形态——低换手直接拉升(自拉) 或 放量逐日拉升(市场跟风)
4. **出货**：必然在下跌过程中出货；高位大阳线→大阴线→慢慢波动下行（常态）

**关键量化抓手**：恐吓vs真跌看换手率；吸筹期=跌不动+重心上移+有支撑；出货=高位放量滞涨/大阴+主力净流出。

**换手率定标（已验证 ✅）**：低/中/高阈值因股而异，用该股自身近半年~1年滚动分位（<p20低 / p20-80中 / >p80高），勿一刀切绝对百分比。
实证（2025~2026分位）：紫金 p10=0.62% vs 烽火 p10=1.51% vs 英维克 p10=2.86%——同样1.5%换手对不同股意义完全不同。

**主力资金数据（✅ 本地就有，不用等外部源）**：stockdb `资金流:{code}*`，含 main_net/main_in/main_out + jumbo_net(超大单)/big_net/mid_net/small_net/retail_in/out，历史1700+天。中兴2026-08-26 示例：main_net -5326万/jumbo -1170万/big -4156万。

## 十、方法论根基：为什么用收盘价（老板补充，2026-09-06）

- **收盘价 = 无未来函数前提下可真实执行的价位**：尾盘最后时段交易价格变化不大，按收盘价买卖是实际可操作的（尾盘交易）
- **开盘→收盘之间全是噪音**（前提：不做日内交易）——日线级策略不认盘中 K 线/分时形态
- 系统设计呼应：score 用 T-1 数据 + T 日收盘成交(fills at close)——**不是图省事，是"算得准不如做得成"**：回测能成交的价，实盘也真能成交
- 推论：盘中"长下影/长上影/分时急拉急砸"若收盘不体现，对日线策略无意义；主力行为识别也应锚定收盘可执行信号（如换手+收盘涨跌），勿被盘中假动作带偏
