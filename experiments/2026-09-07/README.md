# 实盘组合策略 v1.0 无门最终版 (老板模拟盘用, 2026-09-07 独立基线)

## 目标
老板接下来几天用它跑模拟盘。实盘敢用 = 信号少而精 + 纪律明确 + 每天照单可操作。

## 设计(全部来自已验证成果)
- 池: A股大票, 市值≥300亿(630只) + 排除ST/退市
- 买点(纯筹码n=3, 贴东财): 套牢≥60% 且 5%≤底部筹码≤20%
- **无过滤门**(回测铁证: 任何门都砍收益) —— 恐慌底=贴新低/深跌处, 门会把真底和下跌中继一起滤掉
- 卖点: 峰顶跟踪 —— 浮盈≥30%后 跌破持有新高×0.98 或 滞涨15日; 防崩-12%铁律(认错兜底)
- 组合: 每批信号买 4-6 只 × ~1/6资金(组合级验证: K≥6 回撤减半收益翻倍, 见下节)
- 环境开关: 全池信号数/胜率监控; 胜率<40% 环境降仓(见分年验证)

## 交付
- scripts/ 每日信号扫描(收盘后跑) → 明日可买清单(每日生成, 见同目录 PAPER_MMDD.md)
- 规则文档(本文件下方补)
- 9/8 首日清单: PAPER_0908.md(带名称/排序/仓位/纪律卡)

## 策略规则(老板模拟盘照此操作)

### 每日流程(Windows cmd, 收盘后跑一次)
```
cd /d E:\stockgate\Quant_Alpha_System
set PYTHONIOENCODING=utf-8
E:\python\python.exe -B scripts\live_signal_daily.py        (默认自动取最新交易日)
```
→ 输出当日清单(套牢/底部/排序), 按纪律决定次日操作。
注: 也可 `--date 20260907 --top 15` 指定历史日重看。名字对不上代码时查通达信。

### 买入纪律
- 只买清单里 套牢≥60% 且 底部5-20% 的票(纯筹码n=3, 已自动过滤)
- **不设任何过滤门**(回测: 企稳门/深度门/位置门/估值门全部砍收益) —— 清单里的都算数
- 优先(排序用, 不是过滤): 套牢≥80% 且 底部越洗越透(<15%) 的
- **每批信号买 4-6 只**(组合验证: K=1-3赌单票运气, K≥6回撤减半收益翻倍) —— 当日清单前6, 别单挑
- 单票仓位: ≈总资金 1/6 (15-20%), 合计约八成仓, 留二成现金; 卖出回笼资金再补新清单下一只
- 信号多(≥10)说明全市场恐慌, 挑最干净的买; 信号少(<5)说明机会少, 宁缺毋滥
- 接错下跌中继不可怕: 那是防崩线(-12%)的工作, 认错走人, 别扛

### 卖出纪律(铁律, 别自己发挥)
- 防崩: 买入后跌破成本 -12% → 无条件卖(认错)
- 峰顶: 浮盈≥30%后, 收盘跌破"持有期最高价×0.98" → 卖
- 滞涨: 浮盈≥30%后, 连续15日不创新高 → 卖
- 浮盈没到30% = 拿住, 不动(别手痒)

### 环境意识(老板: 防跌不防涨)
- 大盘普跌/信号少的日子: 少买或不买, 宁空仓
- 2026 宏观震荡年: 靠防崩活着, 不追高

## 分年验证(无门版, 200只样本, 交易按入场年归组; outputs/live_byyear.txt)
| 年份 | 交易数 | 股票数 | 几何 | 胜率 | 中位收益 |
|---|---|---|---|---|---|
| 2024 | 528 | 181 | 1.251 (+25%) | 47% | -12.1% |
| 2025 | 298 | 159 | 1.346 (+35%) | 61% | +30.9% |
| 2026(至9/7) | 433 | 185 | 1.013 (+1%) | 37% | -12.1% |

**解读(环境开关实锤)**:
- 策略是"低胜率靠大赢家"型: 2024 胜率47%照样+25%(峰顶卖让赢家跑远), 亏的都被防崩-12%截住
- 2026 胜率37% < 40% → 宏观砸盘年(汇金撤资科技), 筹码逻辑看得到恐慌但看不到宏观拐点
- **环境开关规则**: 滚动监控最近约40笔交易胜率 —— 持续 <40% 就降半仓/空仓等环境(2026就该这么做);
  回到 ≥50% 再恢复满额。胜率是环境仪表, 不是入场过滤器(别把胜率低当天 → 会误杀 2024 那种年)
- 2024-2025 两年(好环境)组合 = 1.251×1.346 ≈ 1.68 (+68%)

**结论(仓位规则定稿)**:
- **K=1~3(只买1-2只)=赌单票运气**: 全程才3-18笔换手, 期末在0.87~1.25乱晃, 回撤23-30%。单票回测的+57%是"每股各自满仓循环"的期望, 真金白银只押1-2只会被选名运气吞掉
- **K≥6 才进入稳定区**: 分散后 回撤减半(12-15%)收益反而上来(+86%~+109%), 12/20/40 收敛不衰减 → 恐慌底策略的正确用法是**一篮子同时买**, 不是单挑
- **规则改为: 每批信号买 4-6 只**(当日清单前6), 每只 ≈ 总资金 1/6(15-20%), 合计约八成仓, 留二成现金; 卖掉才补新清单里的下一只
- 2026年内 K≥6 分年基本走平(+2~4%), 与宏观年判断一致 → 环境开关照旧执行

## 关键验证结果(09-07 回测 200只样本)
| 门 | 几何 | 盈利 |
|---|---|---|
| **无门(纯筹码+峰顶+防崩)** | **1.574 +57%** | 78% |
| 企稳门(不创新低) | 1.134 | 52% |
| 深度门≤-30% | 1.256 | 62% |
| 深度门≤-40% | 1.126 | 41% |
**结论: 任何"过滤门"都砍收益。恐慌底=贴着新低/深跌, 门把它们和下跌中继一起滤掉。
实盘策略 = 无门版: 纯筹码买点(n=3) 照单买, 防崩-12%认错兜底。老板直觉"别接下跌中继"
由防崩线实现(接错了-12%就走), 不由买点前的过滤实现(那会连真底一起滤掉)。**
