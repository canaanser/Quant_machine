## 二、这条链决定三件事

1. **向上汇报**：只有**结论**上行——**组员→组长→总监→老板**；细节留在本层（`AGENTS.md`「老板面纪律」）。
2. **发言权**：老板面只显示 **lead 及以上**；组员要老板知道的事，**先投组长信箱**，由组长**实名**汇总（不许代报冒名）。
3. **可机算**：`leaderOf(slug)` 从名册/卡上取，`chainOf(slug)` 一路向上直到 `老板`。
   **开工自检/派活/验收**都按这条链找"该找谁"。
4. **向下派活（2026-09-13 06:3x 老板定）**：**只能派给直属下一级**——`老板→总监→组长→组员`；
   **跨级/跨组找它的直属上级转**（总监要组员干活 → 派给组长）；**派活三件套**＝卡号＋验收标准＋交付物；
   **谁派谁验**（不许自己给自己签字）；组员**只接自己组长的活**，非本组派单**转给组长**。
   细则见 `AGENTS.md`「派活链路」锚定节。
5. **只用自己名下的人（2026-09-13 06:4x 老板原话：「个人只能用个人手底下的人，不要交叉的去派活」）**：
   **不许借/代指挥/越过别人的上级安排他的人**；**要用人 → 向他的直属上级请求**（对方可拒绝）；
