# 必读矩阵：全局 + 三层（2026-09-13 老板定："按层级把必读拆开"）

> 🔖 **按级别读（每个规矩文档的统一起头）**：先跑
> `node tools/mobile_chat/whoami.mjs --me <你的看板名>` —— 它读**真源**（员工卡／名册），一句话告诉你
> **你现在是哪一级、该读哪几段、看板能不能发言、默认能干什么**。
> **级别一变（组员→组长之类），再跑一次 whoami，清单自动跟着换**——不靠记性，也不靠别人通知。
> 本仓所有规矩文档（AGENTS.md 与 `docs/` 里进本矩阵的那几份）**开头都带同一句抬头**；文中标
> `[member]`/`[lead]`/`[director]` 的段落**只对那一层生效**（`[全员]` 段谁都要读）。

> **规矩**：开工前**按你自己的层级**读对应清单，读完再动手；**读到什么层级，就享什么发言权**。
> 维护：**`codex-总监` 维护本表**；新文档要进清单，**必须写清"给哪一层看"**；过期条目**标记不删**（写"（过期）"）。

## 一、`member`（组员）——在全局之上加

| 读什么 | 要点 |
| --- | --- |
| `docs/RUNBOOK_LOOP.md` **§三 交活格式** | 交活就照那个格式写（缺一项算没交） |
| 你的**信箱**与**工位** | `outputs/dialog/pending_<slug>.ndjson` → 镜像 `.private/<slug>/inbox.md` |
| **发言权**（AGENTS.md §按层级） | **不进老板面**；要老板知道的事 → **先投你组长信箱**，由组长实名汇总 |

## 二、`lead`（组长）——在 member 之上加

| 读什么 | 要点 |
| --- | --- |
| `docs/RUNBOOK_LOOP.md` **全文** | 派活 → 收活 → 门禁 → 回板 → 派下一个 |
| `docs/TASK_ID_STANDARD.md` + `docs/TASK_TEMPLATE.md` | **怎么开卡**（取号规则、必填：标题+承接人+验收标准） |
| `docs/RUNBOOK_ONBOARD.md` | 入职=**显式发牌**（工号永不复用 / 一个会话只属于一条线 / 必须写清批准人） |
| 你名下的组员 | 他们的 `leader` 是你；他们向你汇报，**你实名上板一行** |
| **不许自己合 `main`** | 交活给我（L1）；验收结论落 `docs/reports/<卡号>_review.md` |

## 三、`director`（L1）——在 lead 之上加

| 读什么 | 要点 |
| --- | --- |
| `docs/RUNBOOK_SUCCESSION.md` + `docs/SUCCESSION_TEMPLATE.md` | **承接换人**：岗位不变、工号换代、资产转交；没交接文档不许换人 |
| `docs/RUNBOOK_CREW_HOST.md` | 壳外小工：镜像/门铃/自动合入/自我重载（**沙箱外才有权限**的那一层） |
| `docs/RUNBOOK_KIT_MIGRATION.md` **§六** | 分层纪律：**什么固化（契约层）、什么适配（宿主层）**；判据"换 OS/换 agent/换项目只需改配置而非改代码" |
| `AGENTS.md`「**授权与重启留痕**」 | 常设授权只能老板给；拿到必须登记（谁/范围/影响面/回滚点/风险）；**重启=上线** |
| `AGENTS.md`「**老板面纪律 §两个筐 / 按层级发言权**」 | 必看（要你拍板/故障/撞红线/验收失败/需确认的承诺）与想看的分野 |
| **数据归属** | `level` / `leader` / `gender` / `displayAliases` / `slugAliases` / `joinedAt` 一律**我或老板落**，其余线只读 |
| **合入权** | `main` 的审阅与合入归 L1；门禁 `scripts/crew_review_merge.mjs`（全绿才合） |

## 四、新人入职时怎么用这张表（给 HR）

1. 按**层级**发**对应那一段**（member 发〇+一，lead 加二，director 加三）——**别整包丢过去**；
2. 入职说明里带上：**你的看板名/工号/层级/领导**（四格，都在名册里）；
3. 发完让他回一句「**必读已读 + 一页现状**」（含：我在做什么、下一个动作、卡在哪）。
