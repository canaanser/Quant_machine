## 四、账户级水位闸对照实验(深夜完成, q=基线 K8纯队列 200样本 2024-2026)
| 变体 | 期末 | 峰值回撤 | 水位≥16%天数 | 说明 |
|---|---|---|---|---|
| q (纯队列, 基线) | 2.29 (+129%) | 32.4% | 56 | 维持组合引擎基线 |

**结论: 账户级水位闸/深水减仓在本口径不划算(防崩-12%单票+峰顶纪律已负责风险); 降回撤应从卖出纪律/持仓质量/行业分散入手, 不做账户择时闸。** 实验代码保留(pool_test2.py mode qd, 三档参数在文件内注释)。
- qh(持仓满10交易日未回本卖一半): 触发0次, 与q逐位相同(2.29/+129%/32.4%)。q持仓"要么快+30兑现 要么-12防崩清出", 几乎无10日不涨残留 -> 该纪律在此池形态冗余; "长期阴跌僵尸"在实盘若出现再按需处理(观察: 东方电缆/影石型)。
