# HUB-006 暂停闸：故障即停，停到老板看到为止

- 派单人：老板（口述）　落单：`codex-总监`　接手：`codex-看板编辑`
- **类型**：`dev`（开发）　**严重度**：—　**优先级**：`P1`（阻塞度：故障期间系统会继续往前跑）　**卡住了谁**：全链条的安全阀
- 范围：`tools/mobile_chat/*` 与文档；走**特批通道**（`docs/FASTLANE_20260911.md`）
- 关联：`HUB-003`（向上敲门铃）、`HUB-002`（判忙/派发）、老板 2026-09-11 05:5x 原话：**"遇到那种故障的就暂停呗，停到我看到为止呗。"**

## 一、为什么要它（比推送更可靠）

推送通道（HTTPS/Web Push）解决的是"**想办法通知到老板**"；暂停闸解决的是"**不往前跑，直到老板来看**"。
后者**不依赖任何通道**——手机没电、老板睡觉、页面没开，系统都不会在无人拍板时继续做不可逆的事。

今晚（9/11 凌晨）那次引擎被限网导致**两条线零成交**，缺的正是这个闸：出故障时系统仍在按计划往前跑。

## 二、触发条件

| 级别 | 是否暂停 |
| --- | --- |
| `S1` / `S2` 故障 | **暂停** |
| 任何**涉及钱**的异常（下单/资金/策略参数） | **暂停** |
| `S3` / `S4` | **不停**（记账 + 上板即可） |

## 三、停什么、不停什么（**这条最关键**）

**停**：

- 自动**派活**（不再往任何线投新任务）；
- 自动**唤醒**（不再按点叫线起来干活）；
- **一切涉及钱的自动动作**（建仓 / 下单 / 改参数）。

**不停**（否则"暂停"本身会造成新故障）：

- 已经跑着的**盯盘 / 数据同步 / 常驻引擎**照常运行；
- **取证的活照做**（读日志、留现场）；
- **报告照写**。

**唯一例外**：故障本身要求处置（例如引擎异常要重启），按既有守护流程走——那不是"往前跑"，是"止损"。

## 四、怎么停（必须是"有状态"，不是"靠嘴说"）

1. **一个所有线都能读到的状态**：`outputs/dialog/halt.json` → `{ halted, since, severity, reason, taskId, by }`；
2. **看板置顶红条**：`【已暂停 · 等老板】<原因> · <要你做什么>` + `@老板`；
3. **各线开工自检先读它**（写进 `EMPLOYEE_INIT.md` 的唤醒自检）：处于暂停态 → **不许推新动作**，只许做取证 / 恢复 / 报告。

## 五、谁能解除：**老板的公告**（广播，不是逐条点头）

老板 2026-09-11 05:5x 定调原话：**"等我解决了问题以后，我会发个公告，然后大家都会收到公告，继续开始。"**

**解除信号 = 老板在看板发的公告**（`@全体`，建议格式 `【解除暂停】…`）。

- **只有老板本人发的才算**——任何线不得自行解除，也不得代为转发"解除"；
- **不设自动恢复**——这就是"停到我看到为止"。

**公告一出，系统做三件事**：

1. `halt.json` → `halted=false`，写 `resumedAt` / `by=老板` / `evidence`（公告所在行）；
2. 看板置顶红条改绿条：`【已恢复 · 老板 <时间>】`；
3. 把公告**投到各线信箱**并尝试唤醒（唤醒不通的，靠它们开工自检读状态）。

**诚实口径（重要）**：当前通道下，"大家都会收到"的实际含义是
**"大家下次上场时都会看到"**——**状态是权威的，唤醒是尽力而为的**。
等 `HUB-005` 把注入通道修通，才能变成"公告一发、全员立刻被叫醒"。

**公告必须带"接下来做什么"**（一句即可），否则线醒来会发呆。
恢复同样留痕：谁发的、何时、公告原文在哪一行。

重复提醒：暂停期间每 **30 分钟**在看板重申一次（节流，标"**重复提醒**"），直到解除；避免被忘在角落。

## 六、验收标准

1. 模拟一次 `S1` → 系统进入暂停态、看板置顶红条可见、**后续派单/唤醒被拦**、但**引擎照跑**；
2. 老板说"继续" → 状态解除、动作恢复、留痕完整（谁解的、何时、依据）；
3. `S3` 故障 → **不触发暂停**（只记账 + 上板）；
4. 暂停期间**没有任何线能绕过**（含各线自检拦截）；
5. **老板发 `【解除暂停】` 公告** → `halt.json` 解除、绿条出现、各线自检放行、留痕完整（谁发的/何时/公告原文）；
6. **非老板发的"解除"公告 → 不生效**（要有这条用例，防止有人越权解闸）；
7. 自测脚本补用例并全绿。
