## 一、重大修复：回测数据污染真凶（今晚最关键的工程成果）

- **症状**：回测读表改造后基线异常，strength 字段全是 42 万条文本垃圾。
- **真凶**：合并列错位。主库是旧库 ALTER 加列（strength 在**末尾**），暂存库是新库建表（strength 在**中间**），`INSERT ... SELECT *` 按位置复制 → 把 `created_at` 写进了 `strength`。
- **修复**：`INSERT OR REPLACE ... (显式列名) SELECT (显式列名)`，杜绝按位置复制；清库重扫后 368409 → **609770 条**。
- **教训（老板问"你弄的时候没想到这个问题吗"的答案）**：schema 演进后**列序会变**，升级路径必须测"旧库 + 新代码"，不能只测新库。
- 附带修复：批量合并 ATTACH 超限（SQLite 上限 10）→ 按 8 个一批分批合并；扫描启动清空残留暂存库。
- 基线重定（真实形态信号）：total_return 0.075928 / annual 0.04960 / sharpe 0.31241 / maxDD -0.27393 / 117 笔；之前 0.10556 是"无形态污染"的假象。

## 五、金矿确认（核心成果）

### 早晨之星精选 —— 今晚盖章的真信号
- **条件**：早晨之星 + 深跌>30% + 极致缩量(vol≤0.05) + 大实体(≥0.5) + 短影线(≤0.35)。
- **大样本验证**：胜率 **61.3%**，279 样本，**8/10 年 >56%**（弱年：2023 38.9% / 2026 45.5%），覆盖 **82 只**股票。
- **回测（--signal morning，2017–2026，84 只主池）**：204 笔，净胜率 **60.3%**，+1.96%/笔净，**Sharpe 2.04**；全仓年化 47.5%，20% 仓位年化 8.96%、回撤 -8.1%。

### 4 金矿合并（--signal multi）
- 早晨之星 / 三白兵 / 三只乌鸦 / 长白实体 × 深跌>30%+极致缩量。
- 917 笔，54.3% 胜率，Sharpe 0.93；20% 仓位年化 18.78%、回撤 -23.3%。
- 合并池胜率被稀释但频率和绝对收益更高 → **频率 vs 质量权衡，2–3 形态组合可能是最优**（列入待办）。

### 止盈止损（--tp-sl / --tp-mult，默认 2:1）
- 持仓期内按高低价判定先触哪边，输出退出分布。
- 结果：止损 5% → Sharpe 1.75；10% → 1.94；固定持有 5 日 → **2.04**。
- 结论：**止损越宽越接近固定持有；TP/SL 只做风险保险，不加分**。

### 仓位数学（给老板的答复）
- 20% 仓位 ≈ 1/5 年化；**Sharpe 与仓位无关**；真实分散 = 按持仓数量分摊。
