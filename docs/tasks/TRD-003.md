## 一、问题（有据）

2026-09-11 14:44 引擎 `tail_exec` 应执行 `next_plan`（卖3买2），但抛
`ValueError: not enough values to unpack (expected 5, got 4)` → **一张单未放**（当天靠 14:46 人工接管补回）。
根因：`duty/duty_engine.py` 的 `task_tail_exec()` 构造卖单为 **4 元组** `[code, shares, px, name]`，

## 二、改法（3 行）

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| `task_tail_exec()` 规则卖（防崩/峰顶/滞涨） | `sells.append([e["code"], e["shares"], e["px"], name])` | `sells.append(["SELL", e["code"], e["shares"], e["px"], name])` |
| `task_tail_exec()` 计划减仓 | `sells.append([code, min(int(sh), own), px[code], nm])` | `sells.append(["SELL", code, min(int(sh), own), px[code], nm])` |
| 同码去重 | `if any(s[0] == code for s in sells)` | `if any(s[1] == code for s in sells)`（第 0 位现在是 `"SELL"`） |
