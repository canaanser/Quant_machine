# tray_guard 托盘 UI 统一风格 · 修改说明（2026-09-09）

> 交接给任何后续维护的 AI。改动只涉及**视觉层**，引擎逻辑（duty_engine、重启/启动/退出、下单位置判断）**一行未动**。

## 1. 范围与现状

全部 UI 都在这一个文件里：`duty/tray_guard.py`（约 620 行）。界面共 3 处：
1. **托盘图标** `make_icon()` —— 64×64 纯色圆角块（半径 12），颜色 = 引擎状态（绿=在岗 / 黄=心跳过期 / 红=未运行）
2. **右键菜单** `_popup_run()` + `_rounded_bg()` + `_sep_image()` —— 无边框自绘弹窗（原为**斜切角**，已改**真圆角**）
3. **状态面板** `_panel_run()` —— 左键弹出的 360×240 面板（原为直角方窗 + 固定绿色顶栏，已改**圆角窗 + 顶栏颜色随状态灯联动**）

## 2. 统一后的设计规范（一套 token，全 UI 复用）

| token | 值 | 用途 |
|---|---|---|
| `_BG` | `#f7f8fa` | 所有面板底（弹窗 + 状态面板共用）|
| `_OUT` | `#e7eaef` | 面板描边/按钮描边 |
| `_HOV` | `#dfe6f2` | hover 高亮（菜单行、按钮）|

| `GREEN/YELLOW/RED` | `(46,160,67)/…` | 状态三色：托盘图标 = 彩灯 = 面板顶栏 = 状态文字，四处联动 |
| 字体 | `Microsoft YaHei UI` 9/8（次要行）/11 bold（面板标题）| 全 UI 一致 |

## 3. 各界面改动明细

### 3.1 右键菜单（由"斜切"改"真圆角"）
- **为什么原版不对**：原实现每个角画一个透明**三角形**（`_CHAM=7` 斜切），外形是八角形切角，不是 UI 里说的"倒角（圆角）"。
- **改法**：新增 `_rounded_bg(w,h,r,corner)` —— 用 PIL 画整面板圆角矩形底图，圆角外的像素**按几何距离**（点到圆心距离>半径）强制填成 `_TC`；`draw()` 里删掉"画矩形+四角透明三角"两段，改为直接 `create_image(贴底图)`。文字/hover/分隔/点击逻辑全部没动。
- 关键技术点见 §4。

### 3.2 状态面板（由直角方窗 + 固定绿顶栏 → 圆角 + 状态联动）
- 新增窗口级真圆角：`-transparentcolor _TC` + 最底层一张 `_rounded_bg(360,240,14)` 圆角底图（Canvas `place` 铺满），内容全部装进内缩 14px 的 `shell` Frame（`place` 定位），保证四角弧形区域只属于底图层 → 圆角干净。
- 顶栏颜色从写死 `#1f6f43` 改为**跟随状态灯**：`bar`/标题/✕ 的底色 = 当前状态色（绿/黄/红），与托盘图标、大彩灯、状态文字同源（都在 `tick()` 里统一刷新）。
- 面板底色 `#f2f2f2` → `_BG`；按钮加 `activebackground=_HOV` + Enter/Leave 悬停变色 + 细描边，和菜单 hover 语言一致。
- 顶栏拖动、✕关闭、每秒刷新、单实例 `_panel_lock` 逻辑未动。

### 3.3 托盘图标
未改（实色圆角块在托盘缩放下颜色才准，刻意不加渐变）。

## 4. 关键实现原理（给后续 AI 的避坑清单）

1. **Windows Tk 只有"单色键透明"，没有逐像素 alpha**：`root.attributes("-transparentcolor", _TC)` 是把窗口里颜色==`_TC` 的像素整个变透明。
2. **圆角必须画在 PIL 位图里、圆角外像素填 `_TC`**：Tk Canvas 没有圆角矩形原语，不能靠透明三角去"切"（那就是斜切）。
3. **边缘抗锯齿灰边问题**：PIL 的 `rounded_rectangle` 边缘是抗锯齿的，会混出"半透明灰像素"，这些灰既不是面板色也不是 `_TC`，在颜色键透明下会显示成脏边 → 所以 `_rounded_bg()` 最后一步按**圆心距离**把圆角外像素强制改回 `corner`，得到干净的 1-bit 轮廓（超采样缩小后更平滑）。
4. **别把子控件塞进四角弧形区**：圆角只出现在窗口最外层那圈，所有内容（顶栏、按钮）都要从边缘内缩 ≥ 半径，否则会把弧形区涂掉变回直角。面板用 `shell.place(x=R, y=R, ...)` 保证这一点。
5. **`PhotoImage` 不能跨 Tk 解释器/线程复用**：菜单和面板各自弹窗时现生成底图（`menu_bg`/`bg_img` 是局部变量持引用，防 GC）。
6. **Hover 只改底色不改文字**：菜单文字坐标/颜色与 hover 无关（已满足"文字不跳"）。
7. 分隔线继续用原 `_sep_image()`（中间实、两端融进 `_BG` 的 1px 渐变行），与圆角底图同底色同宽。
