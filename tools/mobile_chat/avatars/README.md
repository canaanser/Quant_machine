# 头像素材目录（HUB-AVATAR）

页面头像图从这里读，**离线、无外链**。

## 命名契约（确定性指派）

- 文件名 = **工号（slug）**，例如 `codex-render.png`、`dsh-main.png`；
- 也认看板名同名文件（如 `codex-渲染.png`），但**工号优先**；
- 扩展名只认 `.png / .jpg / .jpeg / .webp / .svg`；
- 认不到图 → 页面**退回首字圆点**（不会裂图，不会编图）。

## 服务端行为

- 路由：`GET /avatars/<文件名>`（只读这一目录，**不是通用文件服务**）；
- 白名单：文件名只许「字母数字下划线开头 + 点/中划线 + 扩展名」，且解析后必须仍在本目录内（防路径穿越）；
- 缓存：目录索引按 `(mtime, size)` 缓存，**换素材自动生效**，不用重启；
- SVG 额外带 `Content-Security-Policy: default-src 'none'`，禁脚本；
- 目录可换：环境变量 `MCHAT_AVATAR_DIR`（默认就是本目录）。

## 谁放素材

素材由 **codex-看板编辑** 出（人类卡通、男/女两套，按工号确定性指派）；
本目录只提供**取图与退化的接口**，缺素材时页面照常可用。
