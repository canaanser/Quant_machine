## 三、硬口径（写死在卡上，实施不得偏离）

- **两个筐**：**必看**（要你拍板 / 故障 / 撞红线 / 验收或合入失败 / 需确认的承诺）置顶醒目、一行一条、**写清"要你做什么"**；**想看**（结论/收口/进展一行）一行摘要、详情折叠；**其余不看**（线间往来、系统通报）进"协作/通报"折带。**判不准就归必看**。
- **发言权按层级**：老板面只显示 **lead 及以上**；**member 不进老板面**（要汇报先投组长信箱、由组长**实名**汇总，不许代报冒名）；系统角色只发系统事实。**拿不到 level 一律显示（fail-open，宁多勿漏）**。
- **关系链只引用不复制**（老板 03:2x）：真源=员工卡（按 slug）的 `level`/`leader`；名册是投影；**页面不得有组织表副本**；`/api/employees` 每次从真源现算；**关系变动追加 `org_changes.ndjson`**（历史不重写）；页面标"组织表来自 <真源>，更新于 <时间>"。
- **写法纪律**：给老板的消息**首行结论、≤200 字**；发板/投信一律走 `say.mjs --file`（**禁止把正文拼进 shell 引号**）。

## 四、验收

1. 默认视图 = **老板面**（只出必看 + 想看摘要）；关掉开关 = 全量（可对比）；
2. 造 **5 条必看 + 3 条想看 + 3 条不看** → 默认视图只出前两组（必看区与摘要）；
3. 一条 **700 字**长文默认收成 120 字 + 展开；markdown 渲染后**不再出现字面 `**`**；
4. **关系链引用**：临时改某人 `leader` → 页面刷新**自动变**；`org_changes.ndjson` 有记录；"更新于"随真源变；
